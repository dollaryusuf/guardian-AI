🏗️ The Modular DePIN Stack

GuardianAI utilizes a multi-layered infrastructure to ensure machine-to-machine trust and data integrity:
Identity Layer (IoTeX ioID): Every dashcam is provisioned with a unique, non-spoofable hardware identity, anchored on the IoTeX blockchain.
Logic Layer (IoTeX W3bstream): An off-chain compute network that processes real-time telemetry (GPS, Speed, 3-axis Accelerometer). It acts as the "Event Trigger" when G-force anomalies (>4.0G) are detected.
Storage Layer (0G Storage): Rich media evidence (4K video buffers) is archived across 0G's decentralized data grids, ensuring permanent, tamper-proof availability for forensic audits.
Inference Layer (0G Serving): A decentralized AI oracle analyzes kinetic vectors and optical flow from 0G storage to produce a verifiable "Fault Attribution" verdict.
Settlement Layer (IoTeX L1): A Solidity smart contract validates the AI verdict and executes instant stablecoin disbursements from insurance liquidity pools.
